# esx_addoninventory

[Github Link](https://github.com/esx-framework/ESX-Legacy-Addons/tree/main/%5Besx_addons%5D/esx_addoninventory)

Special Inventory for Script, used by esx_society, to store items in a different inventory.

## Usage

There is `two` types of inventories: `shared` and `not shared`.

- Shared inventories **doesn't** belong to a specific user. Example: `foodstore` items
- None-shared inventories are created for **every** user in the server. They are created in db when player is loaded, Example: `esx_property` inventories.

### Database Information

An addon inventory must be configured in the `database` before using it. you **must** run a **server restart** after this.

**Table Structure**

- `name`
    - type: `string`
    - description: name of the inventory
- `label`
    - type: `string`
    - description: label of the inventory (not used)
- `shared`
    - type: `boolean`
    - description:  is the inventory shared with others? (boolean either `0` or `1`)

### API

> **Note:** All these functions are also available as server-side globals (`GetInventory`, `GetSharedInventory`, `AddInventory`, `AddSharedInventory`) since they are declared as global functions in the resource.

#### getInventory

- Event: `esx_addoninventory:getInventory`
  - Usage: `TriggerEvent('esx_addoninventory:getInventory', name, owner, function)`
  - Example:
  ```lua
    TriggerEvent('esx_addoninventory:getInventory', 'property', 'steam:0123456789', function(inventory)
        inventory.removeItem('water', 1)
    end)
  ```

- Global (server): `GetInventory`
    - Usage: `GetInventory(name, owner)`
    - Example:
    ```lua
    local inventory = GetInventory('property', 'steam:0123456789')
    inventory.removeItem('water', 1)
    ```

#### getSharedInventory

- Event: `esx_addoninventory:getSharedInventory`
  - Usage: `TriggerEvent('esx_addoninventory:getSharedInventory', name, function)`
  - Example:
  ```lua
    TriggerEvent('esx_addoninventory:getSharedInventory', 'society_police', function(inventory)
      inventory.addItem('bread', 1)
    end)
  ```

- Export: `exports['esx_addoninventory']:GetSharedInventory`
    - Usage: `exports['esx_addoninventory']:GetSharedInventory(name)`
    - Example:
    ```lua
    local inventory = exports['esx_addoninventory']:GetSharedInventory('society_police')
    inventory.addItem('bread', 1)
    ```

- Global (server): `GetSharedInventory`
    - Usage: `GetSharedInventory(name)`

#### addSharedInventory

Adds a new shared inventory at runtime (inserts it into the database).

- Export: `exports['esx_addoninventory']:AddSharedInventory`
    - Usage: `exports['esx_addoninventory']:AddSharedInventory({name = 'society_police', label = 'Police'})`
    - Parameters: `society` (table with `name` and `label`).
    - Example:
    ```lua
    exports['esx_addoninventory']:AddSharedInventory({name = 'society_mechanic', label = 'Mechanic'})
    ```

### Server globals

```lua
GetInventory(name, owner)                 -- Returns an inventory belonging to a specific owner
GetSharedInventory(name)                  -- Returns a shared inventory
AddSharedInventory({name, label})         -- Creates a new shared inventory
```

> **Note:** When `ESX.GetConfig().OxInventory` is `true`, this resource uses `exports.ox_inventory:RegisterStash` instead of its own tables for shared inventories.
