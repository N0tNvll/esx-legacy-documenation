# esx_lib

`esx_lib` is the official ESX utility library. It provides the global `xLib` namespace, lazy-loaded modules, cross-resource callbacks, pub/sub messaging, reusable client helpers, server validation helpers, shared utility functions and Medal.tv clip integration.

The documentation is split by runtime:

- [Imports](./esx_lib/imports) - how `@esx_lib/imports.lua` creates `xLib` and lazy-loads modules.
- [Client](./esx_lib/client) - keybinds, blips, markers, NUI, DUI, game helpers, cache, streaming, raycasts and client pub/sub listeners.
- [Server](./esx_lib/server) - callbacks, OneSync helpers, player proximity checks, pub/sub, rate limiters and single-use tokens.
- [Shared](./esx_lib/shared) - require/load helpers, validation, math, string, table, classes, timeouts, colors and vehicle plates.
- [Exports](./esx_lib/exports) - direct `esx_lib` exports and runtime server-info version publishing.
- [Usage in ESX](./esx_lib/usage) - current usage patterns found in `esx_core` and `ESX-Legacy-Addons`.

```lua
shared_scripts {
    '@esx_lib/imports.lua',
    '@es_extended/imports.lua',
}
```

Most scripts should use `xLib.*` modules through the import above. Direct exports are available for shared registries and integration points that need to cross resource VMs.
